# Telecom Customer Churn — Production ML Pipeline & ROI Intelligence System
## Overview
This project is an end-to-end Telecom Customer Churn Prediction and Revenue Recovery Intelligence System developed using Machine Learning, Explainable Analytics, and Business ROI Forecasting.

The system predicts customer churn risk, identifies key churn drivers, analyzes revenue impact, and provides retention strategies through an interactive Streamlit dashboard.

---

## Key Features

- End-to-end ML Pipeline
- Leakage-safe preprocessing
- SMOTE imbalance handling
- Logistic Regression model
- Random Forest model
- LightGBM model
- Interactive threshold tuning
- ROC Curve & Precision-Recall Curve
- Feature Importance Analysis
- Customer Risk Scoring
- Business ROI Forecasting
- Revenue Recovery Intelligence
- Retention Strategy Recommendations
- Advanced dark-themed visual analytics
- Interactive Streamlit dashboard
